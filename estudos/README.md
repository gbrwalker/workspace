# Estudos

Esta pasta reúne o material da minha trilha de aprendizado. É mantida no repositório
como **histórico de evolução** — não como vitrine. Os projetos aplicados ficam em
[`../projetos`](../projetos).

## Conteúdo

- **[`ciencia-de-dados-ebac/`](ciencia-de-dados-ebac)** — exercícios e notebooks da
  formação *Profissão: Cientista de Dados* (EBAC), organizados por módulo: dos fundamentos
  de Python e estatística até modelagem, SQL e técnicas avançadas de Machine Learning.

- **[`javascript30/`](javascript30)** — práticas de front-end com JavaScript puro
  (manipulação do DOM, eventos, APIs do navegador), no estilo do desafio JavaScript30.

> O conteúdo aqui é material de curso e prática. Para ver código aplicado a problemas
> reais, ponta a ponta, comece pelos [projetos em destaque](../projetos).
